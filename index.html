     Put Drop in the iPhone share menu

    Do this on the iPhone, once. You build it in Apple's Shortcuts app.

    1. Open Shortcuts, tap +, and name it Drop.
    2. Tap the ⓘ button and turn on Show in Share Sheet.
    3. Add Repeat with Each and set it to Shortcut Input.
    4. Inside the repeat, add Base64 Encode for Repeat Item. Under Show More, set Line Breaks to None.
    5. Still inside, add Get Contents of URL. Paste the address below as the URL. Tap Show More: set Method to POST and Request Body to JSON, then add these five Text fields:
      a = share
      k = paste the key
      from = iPhone
      name = Repeat Item, then tap it and choose Name
      data = Base64 Encoded
    6. Still inside, add Show Notification and put Contents of URL in it.

    Then Share → Drop sends anything: photos, files, links, text (up to 40 MB). If you ever press "Sign out all other devices", copy the new key into the shortcut.
